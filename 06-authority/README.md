# 06 AUTHORITY

Authority defines WHAT IS PERMITTED.

Authorization evaluates:

Subject + Capability + Resource + Place + Service + Action + Context + Policy + Conditions + Scope + Effective Time + Expiration + Delegation + Approval Chain + Revocation.

States:

- PROPOSED
- APPROVED
- REJECTED
- REVOKED
- EXPIRED

Includes team, member, delegated, temporary and emergency authority plus audit.

The absence of effective authorization is not permission.
