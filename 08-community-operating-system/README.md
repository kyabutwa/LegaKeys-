# 08 COMMUNITY OPERATING SYSTEM

The operational system for participating communities.

## Community Operating Workspace
Operates community people, participants, organizations, teams, roles, responsibilities, shifts, schedules, assignments, requests, work orders, tasks, inspections, maintenance, cleaning, security, incidents, deliveries, visitors, providers, facilities, services, finance, access operations, communication, governance, reporting, evidence and operational intelligence.

Community governance includes policies, rules, responsibilities, approvals, delegations and audit.

**A community manages its community context; it does not own or control LegaKeys.**

The two workspaces connect only through governed identity, relationships, context, capability and authorization.
