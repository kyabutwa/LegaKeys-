# Beat Service Catalog

| Service | Canonical responsibility |
|---|---|
| BeatHome | Home, household, unit and home operations |
| BeatUtilities | Water, electricity, gas, internet and waste |
| BeatMaintenance | Requests, work orders, inspections, repairs and evidence |
| BeatFacility | Facilities, reservations, availability and operations |
| BeatCommunity | Community life, requests, activities and operations |
| BeatVisitor | Invitations, guest verification and access windows |
| BeatDelivery | Delivery verification, access and events |
| BeatRide | Mobility discovery, booking and ride events |
| BeatPay | Payment intent, authorization, execution and reconciliation |
| BeatMarket | Products, services, sellers, buyers, orders and fulfillment |
| BeatFood | Food discovery, menus, orders, delivery and payment |
| BeatBnB | Listings, availability, bookings, stays and payment |
| BeatHealth | Health service discovery, requests and appointments |
| BeatGenzi | Learning, skills, education and development |
| BeatWork | Work discovery, opportunities, tasks and relationships |
| BeatGuardian | Safety, assistance, incidents, escalation and handoff |

BeatAccess is foundational and is defined in domain 11.
