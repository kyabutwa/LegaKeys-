```
FACE ID / FINGERPRINT / PALM / QR / NFC / PIN / DEVICE / PHASE ID / ASSISTED VERIFICATION
        ↓
IDENTITY / CREDENTIAL SIGNAL
        ↓

        ↓
CONSEQUENTIAL ACTION
```

Face recognized ≠ authorized to open a door. Fingerprint verified ≠ authorized to enter a facility. Palm recognized ≠ authorized to make a payment.
