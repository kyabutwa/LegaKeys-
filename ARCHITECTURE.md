# LegaKeys Canonical Architecture

## Mission

LegaKeys is an intelligent living infrastructure for participating people and communities.

## Fundamental equation

```
PEOPLE + PLACES + NEEDS + CAPABILITIES + AUTHORITY + ACCESS
+ RESOURCES + CONTEXT + INTELLIGENCE + SERVICES = OUTCOMES
```

## Canonical chain

```
IDENTITY → PARTICIPATION → RELATIONSHIP → CONTEXT → CAPABILITY
→ AUTHORITY → ACCESS / SERVICE → ACTION → EVENT → EVIDENCE
→ OUTCOME → KNOWLEDGE → INTELLIGENCE → PROPOSAL → AUTHORITY AGAIN
```

## Two operating systems

```
                         LEGAKEYS
                            │
               ┌────────────┴────────────┐
               ▼                         ▼
     LEGAKEYS OPERATING SYSTEM    COMMUNITY OPERATING SYSTEM
               │                         │
               ▼                         ▼
      LEGAKEYS WORKSPACE        COMMUNITY OPERATING WORKSPACE
```

The LegaKeys Workspace is where LegaKeys itself is built, governed and operated. The Community Operating Workspace is where participating communities operate their real-world contexts.

## Digital Twin

The Digital Twin represents people, communities, organizations, providers, places, services, assets, equipment, workspaces, teams, relationships and physical entities. It preserves provenance, uncertainty, time and truth state. It never creates authority.

## Access

Interface signals such as device, Face ID, fingerprint, palm, QR, NFC, PIN/code and Phase ID feed BeatAccess. They do not directly grant permission.

## Intelligence

GENESIS understands the world and proposes. CONSTANTYNA understands people and assists. Neither can self-authorize.

## Data ownership

Participant, community, organization and provider data remain controlled by their respective domains. LegaKeys governs infrastructure processing according to authorization, purpose, scope and applicable governance.

## History

Current state may change. Historical events and evidence remain immutable.

## Canonical invariant

**NO AUTHORIZATION → NO CONSEQUENTIAL ACTION.**
