# 02 BEATIDENTITY

BeatIdentity establishes WHO or WHAT an entity is.

It can identify people, communities, organizations, providers, places, phases, buildings, floors, units, common areas, facilities, services, assets, equipment, access points, workspaces, workspace teams and other physical entities.

## Identity core
Identity ID, entity type, state, lifecycle, references and provenance.

## Verification
Verification state, method, evidence, provenance and history.

## Participation
Participation creates a Participant from an identity under defined context and scope.

Identity does not grant authority.
