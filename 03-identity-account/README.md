# 03 IDENTITY & ACCOUNT

Identity and application accounts are different concepts.

## Account
Account ID, state, lifecycle and ownership.

## Authentication
Credential, email authentication, phone authentication, session authentication and authentication events.

## Session
Creation, state, expiration, revocation and the canonical LegaKeys session.

```
IDENTITY ↔ ACCOUNT ↔ AUTHENTICATION → SESSION → PARTICIPANT
```

No passkey/WebAuthn dependency belongs in the canonical architecture.

Authentication never becomes authorization automatically.
