# 09 LEGAKEYS DIGITAL TWIN

The Digital Twin represents the known world: people, communities, organizations, providers, places, services, assets, equipment, workspaces, teams, relationships and physical entities.

## State
Current state, historical state, availability, health, capacity, utilization, connectivity and reliability.

## Sources
Declared, participant, community, organization, provider, workspace, team, operational, device/sensor, external and verified data.

## Truth states
VERIFIED, DECLARED, OBSERVED, INFERRED, PROPOSED, UNKNOWN.

## Governance
Ownership, stewardship, quality, confidence, freshness, access control, privacy, retention and auditability.

The Digital Twin can state UNKNOWN. It cannot create authority.
