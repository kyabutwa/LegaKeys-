# World Invariants

1. Every governed world object has a stable Entity ID.
2. Place is first-class.
3. Place containment is not authority.
4. Location is not authorization.
5. Community is not automatically a parent authority.
6. Place type is explicit.
7. Physical Entity and Resource remain distinct.
8. Relationships are first-class.
9. Relationship subject and object types are validated.
10. Relationship cardinality is explicit where applicable.
11. Relationship validity is temporal.
12. World state retains provenance.
13. Observations retain source and observation time.
14. UNKNOWN remains representable.
15. INFERRED never silently becomes VERIFIED.
16. Current state never replaces historical observations.
17. UI maps, cards and search are derived projections.
18. Digital Twin is derived and never creates authority.
19. No fabricated provider, facility, asset, or location exists in canonical data.
20. External integration state is explicit.
21. Coordinates require explicit precision semantics.
22. Sensitive location data follows scope and privacy policy.
23. Deleting a Place must not silently destroy historical evidence.
24. Cross-world references use stable IDs.
25. Consequential operations remain outside the World layer.
26. World data is relationship-first.
27. Temporal validity is explicit.
28. Provenance survives derived transformations.
29. Community scope does not imply global scope.
30. NO AUTHORIZATION -> NO CONSEQUENTIAL ACTION.
