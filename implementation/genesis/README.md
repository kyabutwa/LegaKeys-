# 14 COMMUNITY INTELLIGENCE — GENESIS

GENESIS is the LegaKeys intelligence runtime for understanding the governed world, detecting meaningful changes, reasoning over trusted context, producing explainable findings and proposals, and feeding governed human/authority decisions.

GENESIS is intelligence, **not authority**.

## Canonical loop

OBSERVE → INGEST → NORMALIZE → UNDERSTAND → CONTEXTUALIZE → DETECT → REASON → SCORE / PRIORITIZE → PROPOSE → HUMAN / AUTHORITY REVIEW → AUTHORIZE → ACTION → EVENT → EVIDENCE → OUTCOME → LEARN → OBSERVE AGAIN

GENESIS may stop at any stage. Authorization and execution remain outside GENESIS.

## What GENESIS understands

- people, participants and relationships
- communities and organizations
- places, buildings, units and physical entities
- capabilities and services
- access and operational state
- actions, events, evidence and outcomes
- needs, intents, patterns and declared objectives
- temporal change and anomalies
- known uncertainty and missing information

## Truth boundary

GENESIS consumes governed facts and derived representations with explicit provenance and truth state.

It MUST distinguish:

VERIFIED ≠ DECLARED ≠ OBSERVED ≠ INFERRED ≠ PROPOSED ≠ UNKNOWN

GENESIS never promotes an inference into verified fact merely because a model is confident.

## Authority boundary

GENESIS may:
- observe
- summarize
- correlate
- detect
- classify
- infer
- forecast
- prioritize
- explain
- recommend
- propose
- request human review
- prepare an action intent

GENESIS may NOT:
- create authority
- grant authorization
- widen authorization scope
- authenticate a person
- create a participant
- unlock access
- move money
- execute a consequential service
- rewrite events/evidence
- fabricate provider availability
- convert UNKNOWN to SUCCESS
- override policy
- self-escalate privileges

Every consequential proposal must pass through the normal:
AUTHORITY → AUTHORIZATION → ACTION → EVENT → EVIDENCE
pipeline.

## Runtime principles

1. Read from governed projections and authoritative sources; do not silently bypass domain boundaries.
2. Every observation carries provenance, source, observed time and ingestion time.
3. Every reasoning run is reproducible enough to identify inputs, model/policy version, prompt/configuration reference and output.
4. Model confidence is not truth.
5. Every consequential proposal has explicit reason, target, expected outcome, risk and required authority.
6. High-impact proposals require explicit human/authority review according to policy.
7. GENESIS cannot approve its own proposal.
8. A failed or uncertain tool call remains failed/unknown.
9. Tool outputs are untrusted until validated and policy-scoped.
10. Sensitive data is minimized and access-scoped.
11. Memory is governed, scoped and deletable according to retention policy; it is not hidden authority.
12. Feedback changes governed knowledge/evaluation state, not historical facts.
13. Safety and governance checks occur before any tool invocation that could create consequential effects.
14. All material GENESIS runs are auditable through Action/Event/Evidence where applicable.

## Operating modes

- OBSERVATION_ONLY — ingest and explain, no proposals.
- ANALYSIS — correlate and reason.
- ASSISTED — produce recommendations/proposals for review.
- GOVERNED_AUTOMATION — may initiate only pre-authorized, bounded low-risk actions through the Action runtime; it never creates authority.
- DEGRADED — operate only on known-safe data and explicitly expose limitations.
- PAUSED — no new reasoning/execution work.

Governed automation is a platform policy mode, not permission for GENESIS itself.

## Release gate

GENESIS is GREEN only when:
- truth/provenance are explicit;
- authorization remains external to intelligence;
- consequential tools cross the Action execution gate;
- model/tool versions are traceable;
- sensitive data is scoped;
- unknown/degraded states are preserved;
- outputs are auditable;
- high-impact cases have human/authority review;
- replay/evaluation can identify the inputs and decisions behind a material output.

**GENESIS does not own authority. GENESIS makes the world understandable enough for authorized humans and governed systems to act.**
